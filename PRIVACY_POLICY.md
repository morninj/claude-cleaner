# Privacy Policy for Claude Cleaner

**Last updated:** February 16, 2026

## Overview

Claude Cleaner is a browser extension that adds a "Delete all chats" button to claude.ai. It operates entirely within your browser and does not collect, store, or transmit any user data.

## Data Collection

This extension does **not** collect, store, or transmit:

- Personal information
- Browsing history
- Chat content
- Cookies or authentication tokens
- Analytics or telemetry data

## How It Works

Claude Cleaner runs a content script on claude.ai that interacts with the page's existing UI elements to select and delete chats. All actions are performed locally in your browser using the same interface available to you manually.

## Permissions

This extension requires no special browser permissions. It only runs on `https://claude.ai/*`.

## Third-Party Services

This extension does not communicate with any external servers or third-party services.

## Changes

If this policy changes, the updated version will be posted here with a new date.
